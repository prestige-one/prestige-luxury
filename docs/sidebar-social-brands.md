# Sidebar social brand colours

Verified against official brand resources on 16 November 2026. These selections apply to
`FloatingContact` only, through the shared desktop/mobile `SocialLinks` renderer. Keyboard
focus shows the same brand treatment as pointer hover. Resting icons stay monochrome.

| Brand | Hover/focus treatment | Official reference |
| --- | --- | --- |
| Instagram | Original gradient icon, saved locally as `web/public/images/social/instagram-brand.webp` | https://www.meta.com/brand/resources/instagram/instagram-brand/ |
| YouTube | `#FF0033` (current YouTube Red) | https://brand.youtube/color/ |
| Facebook | `#0866FF` (current Facebook Blue) | https://www.meta.com/brand/resources/facebook/logo/ |
| WhatsApp | `#25D366` | https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/ |
| LinkedIn | `#0A66C2` (existing LinkedIn blue) | https://brand.linkedin.com/in-logo |
| X | `#000000` | https://about.x.com/content/dam/about-twitter/x/brand-toolkit/x-brand-guidelines.pdf |

Instagram's 180 × 180 WebP is the unmodified Apple touch icon linked from the official
https://www.instagram.com/ page. Source:
https://static.cdninstagram.com/rsrc.php/yw/r/icwX0xAk0pz.webp

YouTube's colour page declares `hex-code1="#FF0033"` for “YouTube Red”. WhatsApp's
own favicon SVG at https://static.whatsapp.net/rsrc.php/y1/r/FJbTMJqMap7.svg declares
`#25d366`. The X brand toolkit specifies X Black as `#000000`.
